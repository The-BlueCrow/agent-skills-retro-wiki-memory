# 新库第一周怎么用

问：wiki 骨架建好了，第一周怎么投喂最不浪费？

答（入库版——重新推导一遍很痛的结论）：

1. **头两天只投喂、不查询**：把手上现成的资料（文章 / 笔记 / 转录）连续投 2–3 份，让目录、标签、互链的缺口暴露出来——缺口在空库上看不见。
2. **第三天读一遍自己的 index**：哪些条目说不清在讲什么，就是标题或归类错了；此时改成本最低。
3. **之后进入常规循环**：有新资料 → ingest 三连（页面 → index → log）→ 跑 lint；有问题先查库再问人——查库是这个库存在的意义。
4. **别第一周就追求完美标签体系**：taxonomy 10–20 个够用，第 20 页之后再合并同类项。

骨架与判断标准见 [[memory-layering|记忆分层]]；写规程类条目时按 [[self-contained-skills|技能自洽原则]] 自查。
