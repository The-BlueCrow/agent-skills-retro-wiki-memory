# 记忆分层：上下文 / 会话 / 长期

智能体的「记性」不是一件事，是三层，各有容量、各有代价：

| 层 | 载体 | 容量 | 丢失方式 |
| --- | --- | --- | --- |
| 上下文 | 单次会话的提示词窗口 | 小，按 token 计 | 会话结束即清零 |
| 会话 | 会话历史 / 摘要压缩 | 中 | 压缩丢细节，久了找不回原文 |
| 长期 | 独立文件（记忆库 / wiki / 教训库） | 近乎无限 | 不主动清就一直在 |

**关键判断**：重推导很痛的知识，写进长期层；一次性问答用完即弃。会话层是缓存不是存储——指望它跨会话记得，等于指望缓存当数据库。

分层的价值在组合：[[self-contained-skills|技能自洽原则]] 让行为可复现，长期记忆让事实可延续，两者的载体都是文件而非会话。查询时先读 [[first-week-setup|新库第一周怎么用]] 建骨架，别先堆内容。
