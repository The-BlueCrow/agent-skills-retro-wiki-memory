# 技能自洽原则

一份可复用的操作规程（技能 / SOP），自洽的判据：**只给这一份文件，不依赖任何外部链接、其他文档、具体机器路径，执行者就能跑对。**

三条落地规则：

1. 判断标准、阈值、口径全部写进正文——"参照某文档"等于把单点依赖换成多点依赖。
2. 路径用占位符（`<SKILLS_DIR>` / `<WIKI>`），不写死某台机器的绝对路径；换环境不用全文替换。
3. 示例自包含：示例本身就是最小可用产物（本库的 `examples/demo-wiki/` 即此原则——拷走就能当 wiki 起点）。

为什么不自洽会烂：引用链一断，读者要么猜、要么去问原作者，文档就退化成"作者的记忆"。同理，[[memory-layering|记忆分层]] 里说的长期层若靠会话回忆而非文件承载，换个会话就失忆。

推送产物时同理：[[push-via-api|直连被墙时用 REST API 推送]] 属于"通道断了换通道"，而不是"等通道恢复"。
