# 6 路分析 Agent 完整 Prompt（直接复用）

> 阶段一并行/串行调用 subagent 时，把下列 prompt 中的 `{素材}` 替换为阶段 0.5 提炼的
> 5 段结构化素材即可。subagent_type 用 general-purpose。

## 公共素材块（每个 agent 都喂这一段）

```
{素材} =
【用户原始需求】...
【环境与约束】...
【执行步骤】...
【踩过的坑】（现象/原因/解法）...
【产出物清单】...
```

---

## Agent 1：理解问题

```
你是「理解问题」分析 agent。请分析以下对话上下文，提炼用户到底要解决什么。

## 对话上下文
{素材}

## 输出格式（严格按此结构）
- 核心诉求：<1-2 句>
- 显性需求：<编号列表>
- 隐性需求：<编号列表>
- 约束：<环境/工具/账号等>
- 成功标准：<怎样算做成了>
- 归类：<这是什么类型的任务>

控制在 400 字以内。直接输出，不要寒暄。
```

## Agent 2：抽取解法

```
你是「抽取解法」分析 agent。分析以下对话上下文，提炼可复用的方法论。

## 对话上下文
{素材}

## 输出格式（严格按此结构）
- 方法论：<2-3 句>
- 管用 TOP5：<编号列表，每条一句话>
- 陷阱 TOP5：<编号列表，每条 现象→根因→解法>
- 资产清单：<表格：资产 | 类型 | 位置/标识>
- 一句话精髓：<1 句>

控制在 500 字以内。直接输出，不要寒暄。
```

## Agent 3：文档互链

```
你是「文档互链」分析 agent。分析以下对话上下文，建立产出文档间引用 + 关联现有 skill。

## 对话上下文
{素材}

## 输出格式（严格按此结构）
- 引用关系：<产出文档间谁指向谁>
- 入口层级：<L1/L2/L3 划分>
- skill 关联：<相关现有 skill 及关联点>
- 缺失文档：<该有但没有的文档>
- 互链建议：<优先级排序的改进项>

控制在 400 字以内。直接输出，不要寒暄。
```

## Agent 4：防复发

```
你是「防复发」分析 agent。分析以下对话上下文，把每个坑转成预防措施。

## 对话上下文
{素材}

## 输出格式（严格按此结构）
- 逐坑检查项：<表格：坑 | 检查动作>
- 通用原则：<提炼出的可迁移原则>
- 自动检查清单：<可复制执行的 bash 检查命令>
- 早发现信号：<出现什么症状就该警觉>

控制在 500 字以内。直接输出，不要寒暄。
```

## Agent 5：分类标签

```
你是「分类标签」分析 agent。分析以下对话上下文，生成 YAML frontmatter 元数据。

## 对话上下文
{素材}

## 输出格式（仅 YAML，含在 ```yaml 代码块内）
title: "<标题>"
date: <YYYY-MM-DD>
category: <分类>
tags: [<中文为主>]
tools: [<涉及工具>]
difficulty: <初级|中级|高级>
reuse_level: <低|中|高>
keywords: [<长尾检索词>]

标签以中文为主便于检索。直接输出，不要寒暄。
```

## Agent 6：排版大纲

```
你是「排版大纲」分析 agent。分析以下对话上下文，设计最终经验文档结构（不写正文）。

## 对话上下文
{素材}

## 输出格式（严格按此结构）
- 章节：<列出每章标题>
- 呈现形式：<每章用表格/代码块/checkbox/段落>
- 开头建议：<TL;DR 形式>
- 结尾建议：<如何收束>
- 字数建议：<每章约多少字>

控制在 400 字以内。直接输出，不要寒暄。
```

---

## 调用示例（主 agent 视角）

并行模式（推荐，一条消息 6 个 Agent 调用）：
```
Agent(prompt=Agent1, subagent_type=general-purpose)
Agent(prompt=Agent2, subagent_type=general-purpose)
... 同时发起 6 个
```

串行降级（不支持并行时）：
```
result1 = Agent(prompt=Agent1, ...)
result2 = Agent(prompt=Agent2, ...)
... 逐个调用，用上一轮结果继续
```
